# Accessibility and responsive UI

Test mobile widths, zoom, keyboard use and long content. Use semantic elements and
existing accessible primitives. Label icon-only actions and maintain visible focus.
Aim for comfortable 44px touch targets; essential actions cannot depend on hover.
Use hover enhancements only on capable devices and legible mobile input sizes.

Dialogs manage focus and return it to the trigger. Hidden content cannot remain
in the tab order. Do not force focus/scroll on every render. Announce useful status
changes without flooding live regions with every countdown tick. Respect reduced
motion and maintain readable text/control contrast.
